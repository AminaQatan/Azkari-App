أذكاري — نسخة جاهزة للاستضافة المجانية

النشر على Cloudflare Pages:
1. افتحي https://dash.cloudflare.com وأنشئي حساباً أو سجلي الدخول.
2. انتقلي إلى Workers & Pages ثم Create application ثم Get started ثم Drag and drop your files.
3. اختاري اسم المشروع، مثلاً azkari-amina، وارفعي ملف Azkari-Free-Hosting.zip مباشرة دون فك الضغط.
4. اضغطي Deploy site أو Save and Deploy حسب الشاشة.
5. افتحي رابط pages.dev الذي يظهر بعد نجاح النشر. للوصول إلى السبحة مباشرة أضيفي /#tasbih إلى عنوان الموقع.

اسم azkari-amina مثال مقترح فقط ولم يتم حجزه أو نشره. سيظهر العنوان الفعلي بعد النشر.
الموقع لا يحتاج إلى بناء أو تثبيت حزم أو قاعدة بيانات. يوجد index.html مباشرة في جذر ملف ZIP.
روابط مشاركة السبحة تأخذ عنوان الاستضافة الجديدة تلقائياً. بعد النشر أنشئي روابط مشاركة جديدة من الموقع الجديد.
يمكن فتح روابط السبحة القديمة على الموقع القديم؛ لا تتحول تلقائياً إلى العنوان الجديد.
المفضلة والإعدادات والعدادات محفوظة في متصفح كل زائر ولا تنتقل تلقائياً بين النطاقات. لا يوجد مجموع مشترك لعدّ الزوار.
هذه حزمة موقع قابلة للإضافة إلى الشاشة الرئيسية، وليست ملف APK أو IPA.

التحديث لاحقاً:
افتحي نفس مشروع Pages واختاري Create a new deployment ثم Production وارفعي الحزمة الجديدة.

بديل GitHub Pages:
فكي الضغط وارفعي محتويات الحزمة إلى مستودع عام، مع وجود index.html في جذر المستودع.
من Settings > Pages اختاري Deploy from a branch ثم main ثم / (root) ثم Save.
يمكن استخدام الحزمة أيضاً على خدمات الاستضافة الثابتة الأخرى.

المصدر وتعريف الخطوط موجودان داخل التطبيق وفي assets/FONT-LICENSE.txt.
